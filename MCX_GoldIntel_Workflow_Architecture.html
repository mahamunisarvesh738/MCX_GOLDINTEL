Executive Problem Statement Alignment:
MCX lists gold futures across multiple contract sizes (100g, 10g, 8g, 1g) and purities (995 vs 999). Because they represent the same underlying precious metal, normalized prices should align. This terminal mathematically normalizes all contracts to INR per 10g of 999 Fine Gold, isolates term-structure carry, simulates execution with full Indian statutory friction (CTT, SEBI, stamp duty, GST, slippage), and enforces strict quiet-mode signal hygiene.

1 End-to-End System Workflow Architecture

The application is architected across six decoupled processing layers to guarantee mathematical rigor and high execution speed:

Layer 1
Ingestion & Validation

Pulls MCX Daily Bhavcopy or accepts CSV upload. Intercepts holiday rollover traps and sanitizes space-padded strings.

Layer 2
Normalization Engine

Normalizes contract sizes and converts 995 fine gold to 999 fine standard: INR / 10g of 999 Fine Gold.

Layer 3
Relational Store

PostgreSQL on Render with seamless zero-config local engine fallback for instant prototype evaluation.

Layer 4
Carry & Term Structure

Builds non-continuous futures curves, computes implied financing repo rates, and separates roll-down from curve shifts.

Layer 5
Walk-Forward Backtest

Strict day-by-day chronological replay. Accounts for MCX turnover fees, CTT, SEBI, Stamp duty, GST, and dynamic slippage.

Layer 6
Intelligence & Suppression

Filters spurious noise (|Z| < 2.0σ), blocks trades during tender windows or illiquid periods, and suppresses phantom spreads.

2 Mathematical Normalization Formula

To eliminate quotation scale differences and purity basis mismatches, every settlement price is normalized to INR per 10 grams of 999 Fine Gold (24K standard):

Universal Bullion Normalization Formula
Price_norm = Price_quoted × (10 / QuoteUnitGrams) × (0.999 / PurityFactor)

6 1-Click Render Deployment Instructions

The repository includes a ready-to-use Render Blueprint (render.yaml):

  1. Push repository to your GitHub account: git remote add origin <url> && git push -u origin main
  2. Log into dashboard.render.com and click New + ➔ Blueprint.
  3. Select your repository. Render automatically reads render.yaml, provisions the PostgreSQL database (mcx-bullion-db), builds the React client, and starts the Express web service.
  4. The live application URL is generated automatically (e.g. https://mcx-bullion-intel.onrender.com).
